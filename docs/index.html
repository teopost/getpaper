Data control

Your documentation. Your infrastructure. Your control.

GetPaper is software you run, not a service you sign up for. Install it yourself and your documentation is never handed to a platform hosted by the GetPaper project: it stays in the environment you choose and administer.

Choose where it runs

Any host that runs Docker containers (amd64 or arm64): on premises, in your data centre or with the cloud provider you already use. You can also build it from source.

Know where the data is

Everything lives in two places you control: the PostgreSQL database and the attachments volume. Nothing is kept anywhere else by the application.

Back up on your terms

Use your usual database and volume backup tools. Workspace admins can also export a complete GetPaper backup (ZIP) and restore it on another installation.

Decide who gets in

Microsoft Entra ID or password sign-in, invite-only access, allowed email domains, private collections. Superadmins can switch off exports and public links for the whole installation.

A note on AI tools. Self-hosting controls where GetPaper stores your documentation. When you connect an AI assistant through MCP, the content it reads is processed by that assistant and the model it uses, under their own terms. Choose and configure those tools with the same care.

Features

Everything a team wiki needs, ready on day one.

A focused editor and a clear structure keep documentation alive. Organise it by team, project or client and find it again in seconds.

A Markdown editor that stays out of the way

Slash commands, tables, checklists, callouts, code blocks with syntax highlighting and Mermaid diagrams. Saved as plain Markdown.

Multiple workspaces

Separate workspaces for teams, departments or clients, each with its own members, roles, collections and API keys. Move documents between them with their history.

Search across workspaces

Full-text search with highlighted matches, a collection filter and one switch to search every workspace you belong to.

Roles, groups and permissions

Admins, editors and viewers; groups with read or edit access; collections that are editable, read-only or private.

History and collaboration

Revision history with restore, comments with replies, @mentions with notifications, templates, drafts and a 30-day trash.

Share and export

Read-only public links (kept out of search engines), downloads as Markdown, HTML, PDF or Word, and a presentation mode.

For IT administrators

Sign in with Microsoft Entra ID, on your rules.

If your organisation uses Microsoft 365, people sign in with their work account. GetPaper uses Microsoft Entra ID (formerly Azure AD) through OpenID Connect, with the authorization code flow and PKCE.

  • Accept a single tenant or restrict sign-in to your email domains
  • Create accounts at the first sign-in, or let in invited people only
  • Turn off password sign-in for an SSO-only installation
  • Superadmin switches for backups, Markdown export and public links
  • Your product name and colours on every page and email

Migration

Move to GetPaper without starting over.

Looking for a self-hosted alternative to Confluence or Outline? Export your spaces or collections, upload the ZIP, and GetPaper rebuilds the page tree, rewrites links and keeps your attachments. The import recognises the format automatically.

Confluence

Cloud, Server and Data Center · XML or HTML space export (ZIP)

Imported

  • Page hierarchy and order; with XML, creation and modification dates
  • Images, attachments and links between pages
  • Info, note, warning and tip panels as callouts; code blocks with their language; expand, task lists, tables and statuses

Not imported

  • Authors, comments, version history, labels and permissions
  • Dynamic macros; PDF exports are not supported

Outline

Markdown export (ZIP)

Imported

  • Collections and nested documents
  • Images, attachments and links between documents
  • Microsoft sign-in can reuse the app registration of an Outline instance on the same domain

Not imported

  • What the Markdown export does not contain: comments, revision history, users and permissions

Notion, Obsidian and more

Markdown, HTML or text files, alone or in a ZIP

Imported

  • Markdown exports from Notion, Obsidian, Wiki.js, GitBook and BookStack
  • Folders as collections and nested documents; Obsidian [[wiki links]] rewritten
  • GetPaper backups, to move a workspace between installations

Imports are a one-time conversion of exported files, not a live sync. Try a test workspace before moving a whole team. Confluence, Outline, Notion and the other names are trademarks of their owners; GetPaper is not affiliated with them.

AI & MCP

Connect AI assistants, within the limits you set.

GetPaper includes a Model Context Protocol (MCP) server. Compatible clients such as Claude Code, Claude Desktop or Cursor can search and read your documentation and, if the key allows it, create and update documents.

  • Read-only or read/write API keys, with an optional expiry
  • Limit a key to some workspaces or some collections
  • Never more permissions than the person who created the key; keys cannot manage members or settings
# add your wiki to Claude Code
claude mcp add --transport http getpaper \
  https://wiki.example.com/mcp \
  --header "Authorization: Bearer ol_api_…"

Example: publish a local Markdown wiki

You ask your assistant

Publish my local Karpathy-style LLM wiki in ~/notes/llm-wiki to GetPaper, in a new collection called "Research". Keep the folder structure.

An assistant that can read your files (for example Claude Code) and has a read/write GetPaper key.

What happens

  1. The assistant reads the Markdown files on your computer, with its own file access.
  2. create_collectioncreates "Research" in the workspace allowed by the key.
  3. create_documentpublishes each page, nested under its folder page with parent_document.
  4. update_documentturns [[wiki links]] into links to the new documents.

Images and attachments are not uploaded through MCP: for a folder with attachments, the ZIP import is the better route.

Install

Up and running in three steps.

One Docker Compose file starts GetPaper and PostgreSQL from the image on GitHub Container Registry. No build, no external services required.

1

Download

The Compose file uses the published image for amd64 and arm64.

2

Configure

Set at least the public URL and a database password. Microsoft sign-in and email are optional.

3

Start

Open the URL and create the first account: it becomes the superadmin.

# 1. Download
mkdir getpaper && cd getpaper
curl -fsSLO https://raw.githubusercontent.com/teopost/getpaper/main/deploy/docker-compose.yml

# 2. Configure: set at least URL and POSTGRES_PASSWORD
curl -fsSL https://raw.githubusercontent.com/teopost/getpaper/main/.env.example -o .env
nano .env

# 3. Start
docker compose up -d

Requirements

A host with Docker and Compose. PostgreSQL 16 is included in the Compose file.

Updates

docker compose pull && docker compose up -d. Pin a release (e.g. 0.1.0) in .env for controlled updates.

Where data lives

Docker volumes pgdata (database) and uploads (attachments): include both in your backups.

Configuration

Sign-up policy, Entra ID, SMTP, defaults: all through environment variables.

FAQ

Frequently asked questions

Is GetPaper free and open source?

Yes. The source code is on GitHub under the MIT license, and the Docker image is published on GitHub Container Registry. You can use, study, modify and redistribute it under the terms of the license.

Where are my documents stored?

In the PostgreSQL database and the attachments volume of your own installation. Wherever you run GetPaper - your own server, a virtual machine or a cloud account you manage - that is where the documentation lives.

Do I need an account or a licence key from the GetPaper project?

No. You install the software yourself. The server only connects to the external services you configure: Microsoft Entra ID for sign-in and your SMTP server for emails. It contains no telemetry and no licence check.

Which single sign-on providers are supported?

Microsoft Entra ID (formerly Azure AD) through OpenID Connect. Email and password sign-in is also available and can be turned off. Google, Slack and generic OIDC providers are not supported.

Can I migrate from Confluence or Outline?

Yes. GetPaper imports Confluence space exports in XML or HTML format, with page tree, dates, attachments and the most common macros, and Outline Markdown exports with collections, nested documents and attachments. Authors, comments, version history, labels and permissions are not imported.

Does the MCP server send my documents to an AI provider?

GetPaper does not send anything to AI providers. The MCP server answers the AI assistants you connect with an API key, within the permissions of that key. What the assistant then does with the content depends on the assistant and the model you use.

How is GetPaper different from Outline?

GetPaper is inspired by Outline and has a Rust backend. Multiple workspaces, Confluence import and an MCP server are included. It has no real-time co-editing (conflicts are detected on save), comments refer to the whole document and the only SSO provider is Microsoft Entra ID.
